# Characters

Each character is one skill with its own job. It calls the [tools](../tools/README.md) and nothing else, and only when the task needs them. A character file also holds a short stance, a plain description of what its craft puts first and refuses. It is not a voice.

## User-invoked

None yet.

## Model-invoked

- **[bayer](./bayer/SKILL.md)**: The graphic designer. Brand, logos and HTML email, from a brief file and the project's own rules.
- **[breuer](./breuer/SKILL.md)**: The screen designer. App and web screens, from a brief file and the project's own rules, with a spec and an image of each state.
- **[gropius](./gropius/SKILL.md)**: The lead. Frames the brief, hands the piece to the right designer and runs the craft pass on pieces made elsewhere.
- **[mies](./mies/SKILL.md)**: The space designer. Form, plans and structure, from a brief file and the project's own rules, handed back as a design study with its figures and an image.
- **[moholy-nagy](./moholy-nagy/SKILL.md)**: The shot and motion designer. Shot lists, storyboards and animated titles, from a brief file and the project's own rules, handed back as a plan and a draft, not a cut.
- **[ogilvy](./ogilvy/SKILL.md)**: The writer. The idea, the insight, the story and the words of every piece made here, from the brief's intake and the research, handed to the designer as the brief and a words file.
