# Develop references

What photograph work rests on. A brief cites a row by its id and says which rule it took. A rule in `SKILL.md` rests only on a row marked `opened`.

Every craft row here is a Wikibooks or Wikipedia page, so every one is `secondary`: a summary read on the date given, not a primary work. No primary craft book on photography was found or searched, so there are no lending books and no pointer rows. A page is cited for the section its pointer names, and each rule is a one-line paraphrase with no copied text. A row whose rule says the page is short or thin is a weak base: a rule that rests only on it says so.

The LightCraft row is a tool row. It is cited for how the app is driven, never for a craft rule.
