# Storyboard references

What the storyboard and the animatic rest on. A brief cites a row by its id and says which rule it took. A rule in `SKILL.md` rests only on a row marked `opened`. A row marked `not opened` is a pointer to a work nobody here has read: its rule is inferred from the title, and it is listed, never cited.

Every row from Wikibooks or Wikipedia is secondary: a community text, read in full for a Wikibooks page and by its summary for a Wikipedia page. The rules are paraphrased in one line each and nothing is copied. The lending books are pointers only.
