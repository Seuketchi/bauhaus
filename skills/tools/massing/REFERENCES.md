# Massing references

What massing work rests on. A brief cites a row by its id and says which rule it took. A rule in `SKILL.md` rests only on a row marked `opened`. A row marked `not opened` is a pointer to a work nobody here has read: its rule is inferred from the title, and it is listed, never cited.

Lending books are pointers only: title, edition, a place to find it and a one-line paraphrase. No passage is copied.
